# madrasa-platform

Онлайн-платформа для воскресной школы, медресе, репетиторства и платных курсов. Личные кабинеты ученика, родителя, устаза, бухгалтера и администратора.

## Что уже есть (этап 1)

- Вход по e-mail или телефону, регистрация по одноразовой ссылке-приглашению (14 дней).
- Роли: администратор, устаз, ученик, родитель, бухгалтер. У одного человека может быть несколько ролей.
- Отделения (медресе, воскресная школа) и группы для братьев, сестёр или смешанные. Сестра не попадёт в группу братьев и наоборот.
- Журнал устаза: уроки (очно или со ссылкой на онлайн-урок), посещаемость, зачёт «сдал / не сдал», необязательный балл и комментарий.
- «Сегодня» для ученика и родителя: ближайшие уроки, домашнее задание, последние отметки. Страница результатов «сдано N из M».
- Родитель видит только своих детей, устаз только свои группы.

## Запуск

Нужны Node.js 22 и PostgreSQL 16.

```bash
npm install
cp .env.example .env        # укажите DATABASE_URL и SESSION_SECRET
npm run db:migrate          # создать таблицы
npm run db:seed             # демо-данные (пароль у всех: password123)
npm run dev                 # http://localhost:3000
```

Первый настоящий администратор без демо-данных:

```bash
npm run create-admin -- "Имя Фамилия" admin@example.com "длинный-пароль" MALE
```

Часовой пояс школы задаётся переменной `APP_TIMEZONE` (по умолчанию `Asia/Yekaterinburg`).

## Проверки
